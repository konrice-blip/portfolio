## 👋 About Me
I have been studying web development and design for about **3 months** now. I really enjoy the visual side of websites, which got me super interested in **UI/UX design**. I like figuring out how to make sites look clean, organized, and easy for people to use. And, honestly, I sometimes use AI as a tool to help explain tricky concepts, fix bugs, or brainstorm logic when I get stuck. However, I make sure not to rely on it. I write my own layouts, practice the code myself, and ensure I actually understand how everything works under the hood.
